# Changelog  

All notable changes to this project are documented in this file.  

## [0.0.6] - 2026-07-20 

### Updated  

- Revised stop estimates process to use the most relevant historical GTFS for a given month.
- Added Performance Metrics Dashboard.

## [0.0.5] - 2026-04-22 

### Updated  

- Revised fare and stop estimates slightly downwards. Fare totals were overstated due to the inclusion of some incomplete Genfare Link transactions.

## [0.0.4] - 2026-04-13 

### Updated  

- Changed ridership productivity measure to use Vehicle Revenue Hours (VRH) instead of Vehicle Hours (VH). VRH reflects when vehicles are actively in service and available to carry passengers, providing a more accurate measure of route productivity.  

## [0.0.4] - 2026-03-16 

### Updated  

- Added new fare datasets detailing the Fare Capture Method and Funding Source  
- Revised fares dashboard to be able to display more than six months of data  
- Revised fare group and type names for consistency and clarity

## [0.0.4] - 2026-03-06 

### Updated  

- Added February ridership data

## [0.0.3] - 2026-02-24 

### Updated  

- Revised mobile fare data to correct duplicated fare cap charges. These errors overstated the volume of mobile fare cap transactions and understated the number of regular and discount mobile transactions.

## [0.0.2] - 2026-02-13  

### Updated  

- Added January data to all datasets.  
- Revised stop totals following GTFS stop updates (added inbound City Center stop).  
- Updated October fare totals due to delayed fare uploads.  

## [0.0.1] - 2026-01-14  

### Added  

- Fare, ridership, and stop-level boarding datasets.  
- Dashboards for each dataset category.
